What it does

  • Browse — 47 matrices across 26 Elastic doc pages, searchable and filterable by support status, with a per-row citation.
  • Is my stack supported? — enter your Stack version, Elastic Agent version, ingestion path, SDKs and agents; get a verdict per component.
  • Classic APM → EDOT migration gaps — what has no EDOT equivalent yet, what needs rework, what migrates cleanly.
  • Feature availability by SDK — which EDOT SDK covers the features you need, and at which version.

How it avoids guessing

The engine holds no compatibility knowledge of its own. All 40 rules carry the documentation sentence that justifies them, and a build gate asserts every quote appears verbatim in the scraped data — a rule cannot cite text that isn't on a page we actually read. Seven combinations Elastic does not document are declared as such and reported as Not documented rather than given a verdict.

Known limitations
  • 8 of 18 datasets cannot yet be refreshed automatically — the per-language EDOT SDK pages live outside elastic/opentelemetry. Their data is valid but drift in them is not detected.
  • A full refresh cycle has not completed end to end with live data.
  • Elastic's documentation is the authoritative source. If a page has changed since the scrape date shown in the app, the doc wins.
